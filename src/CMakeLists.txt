# Shadcn component library (QML) -- STATIC QML module. Consumers add_subdirectory
# then link shadcn_ui + shadcn_uiplugin and, on the QML side, import Shadcn
# (components are unprefixed: Button / Input / ...).
#
# Sources are grouped one directory per component family under qml/ (mirroring
# examples/gallery/demos/); qml/core/ holds the shared primitives (Theme,
# FocusRing, RoundedImage). Type names stay flat (the subdirectory does not
# namespace them), so imports and cross-references are unaffected.
